# История версий

## 0.9.0 — 2026-11-25

- Свежая сборка инструментов модели, чертежей и спецификаций; обновлены справка и навык агента.
- Интеграция cad-lab устанавливается из публичного GitHub и использует MCP-мост бинарной поставки.
- Пакет интеграции содержит собранные модули приложения и навык, без TypeScript, Python-исходников и карт исходного кода.
- CAD runtime поставляется в DLL и Python bytecode со встроенным интерпретатором; отдельный Python и uv не нужны.
- Инструкции разделяют установку библиотеки в КОМПАС и подключение инструментов в приложении.

## 0.8.1 — 2026-11-09

- Индикатор «Агент изучает модель» снимается через 15 секунд после последнего вызова вместо 90.
- Чертежи: перепривязка ассоциативных видов к другой модели, сохранение штампов всех листов при перестроении,
  явная привязка концов размеров и текст под размерной надписью.
- Технические требования: настройка высоты шрифта и исправление обработки блоков переполнения.
- Чтение спецификаций: корректное суммарное количество в сгруппированных строках.
- Справка по вспомогательным библиотекам для агента и улучшения чтения чертежей.
- Уточнена совместимость: КОМПАС-3D v19 и новее (x64); на более новых версиях возможны небольшие отклонения в работе.
- Переименование в cad-lab и защита поставки от включения внутренних материалов.

## 0.8.0 — 2026-10-28

Первый публичный релиз. Главное в нём:

- Установщик сам прописывает MCP-сервер в Claude Code, Claude Desktop, Cursor, VS Code (Copilot), Codex,
  Gemini CLI, Windsurf и LM Studio и кладёт навык `kompas-engineering` в их папки навыков.
- Инструмент `feedback`: отзыв разработчикам с согласия человека в чате; выключается `install.ps1 -Feedback off`.
- Свой КОМПАС агента: `instance_start` запускает отдельное окно КОМПАС, чтобы агент не мешал вашей работе.
