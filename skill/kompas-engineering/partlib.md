# partlib — «Стандартные изделия» из скрипта

Библиотека-адаптер приложения «Стандартные изделия» (PARTLib) КОМПАС-3D v19. В неймспейсе `code_exec`,
`query`, `test_exec` — имя `partlib`. Поиск и параметры — в любом канале; вставка и правка — внутри этапа
(`code_exec`), одной записью отмены вместе с остальным скриптом.

**КОМПАС v23** PARTLib не поставляет. Либа берёт `Libs\PARTLib` своей установки, а нет его — папку подключённого в КОМПАС приложения «Стандартные изделия» (на этой машине v23 держит подключённым PARTLib от v19 — работает); нет и его — `PartLibError` с кодом `no_app` (где искали — в `extra.searched`).

## Каталог

```python
hits = partlib.find("болт 7798", need="3d")       # {total, classes: [{id, name, path, 2d, 3d}]}
partlib.folders("Крепежные изделия/Болты")        # {folders, classes} — дерево каталога
cls = hits["classes"][0]["id"]                    # или точное имя: "Болт ГОСТ 7798-70 (исп 1)"
partlib.info(cls, values=True)                    # {id, name, grids: [{grid, name, rows, params: [{name, code, values}], selected}], part, context}
partlib.rows(cls, 0, {"Диаметр резьбы": 12})      # типоразмеры с фильтром: {total, rows: [{row, values}]}
s = partlib.select(cls, {"Диаметр резьбы": 12, "Длина болта": 40, "Шаг резьбы": 1.75, "Размер под ключ": 18})
s["designation"]   # «Болт М12-6gx40 (S18) ГОСТ 7798-70»
s["attrs"]         # [{name, value, code}] — масса, длина резьбы, код ОКП…
s["location"], s["locations"]   # ключ изделия: PART:… (и NEWLOC/FAVLOC/SHORTLOC)
```

- Параметр — имя из `info` (регистр и «ё» не важны), его код или `"сетка.номер"` (оба номера с 0; в сетке
  бывают скрытые параметры, которых `info` не показывает, — номера сдвигаются, надёжнее имя); значения
  сравниваются как строки (`1.25` == `"1,25"`). Имена у разных классов разные (у болта 7798 «Диаметр
  резьбы»/«Длина болта», у винта 11738 «Номин диаметр резьбы»/«Длина изделия») — смотрите `info`.
- Сетки без условий — на строке по умолчанию справочника (перед каждым вызовом выбор сбрасывается, история
  вызовов на обозначение не влияет). Строка по умолчанию — какая есть в справочнике: у болта — без группы
  прочности и материала, у шайбы ГОСТ 11371 — материал АД1 (алюминий). Нужные группу прочности и материал
  («Наименование») задавайте явно.
- `find` ищет по словам названия и пути (и номеру ГОСТ): «болт 7798», «шайба 11371»; «болт М12» и «DIN 933» не
  найдутся.
- Условиям отвечает несколько типоразмеров — `select` берёт первый и кладёт `ambiguous` (что ещё
  меняется), а `insert*` отказывают `ambiguous` со списком: у болта М12×40 есть шаги 1,25/1,5/1,75 и
  размер под ключ 18/19 — шаг и S задайте явно.
- Ошибки — `partlib.PartLibError` (`code`, `message`, `extra`): `no_class` (кандидаты), `no_param` (параметры
  по сеткам), `no_row` (`near`: какие значения есть при остальных условиях), `ambiguous`.
- **Таблицы типоразмеров большие — не выводите их целиком.** У кольца ГОСТ 9833 больше 10 000 строк, у шпильки
  ГОСТ 22032 — 2 000; `rows` по одному условию отдаёт до `limit=50` строк со всеми параметрами, а `info(values=True)` —
  списки значений всех параметров. Порядок, который стоит дешевле всего:
  1. `info(cls)` без `values` — только имена параметров по сеткам;
  2. сразу `select(cls, {все известные условия})`: попали — обозначение и атрибуты; `no_row` — в `extra.near`
     значения, которые есть при остальных условиях; `ambiguous` — что ещё меняется (`varies`);
  3. `rows` — только чтобы выбрать из ряда, с условиями по всем известным параметрам и узким `limit`
     (`partlib.rows(cls, 0, {"Диаметр штока": 57}, limit=10)`); в ответ скрипта кладите нужные колонки, а не всю
     строку (`[r["values"]["Длина шпильки"] for r in …["rows"]]`).
- Каталог работает в отдельном процессе (внутри КОМПАС COM-модель справочника его роняет): первый вызов
  ~1 с, дальше — мгновенно. `partlib.stop()` — перезапустить процесс.

## Вставка

| документ | вызов | результат |
|---|---|---|
| сборка | `partlib.insert(cls, values, at=(x, y, z) \| matrix=[16])` | `IPart7` компонента |
| чертёж, фрагмент | `partlib.insert_2d(cls, values, at=(x, y), angle=0, view=None)` | `IMacroObject` |
| спецификация | `partlib.insert_spec(cls, values)` | строка (объект спецификации) |

- Вставка — тихим путём самой библиотеки: модель или 2D-метод с переменными типоразмера, имя компонента =
  обозначение, масса из справочника, **объект спецификации создаётся сам** (раздел «Стандартные изделия»).
- Документ этапа на время вставки делается активным и возвращается (библиотека пишет в активное окно).
- 3D: ответ справочника берётся вне КОМПАС (~1–2 с). Начало компонента — у крепежа опорная плоскость
  головки, ось изделия — Z, стержень в −Z (проверяйте габарит `inspect` для своего изделия). Положение —
  `at`/`matrix`, затем сопряжения API сборки по граням (`find type=face within comp:…` — грани изделия есть) и оси компонента (`Axis` в его вспомогательной
  геометрии).
- 2D: ответ строит справочник в самом КОМПАС (только там 2D-метод под чертёж): окно открывается прозрачным
  и закрывается само, ~1,5 с. `at` — точка вставки в системе активного вида, `angle` — градусы, `view` —
  `front|top|left|right` (спереди/сверху/слева/справа), если 2D-метод изделия выбирает вид (иначе `no_view`;
  у болта, гайки, подшипника 205 2D-метод вид не выбирает — рисуется только основной вид).
- Каждая вставка — свой компонент и своя строка спецификации (4 одинаковых болта — 4 строки по 1 шт.).
  Обозначение в 2D-макроэлементе пишется с пробелом («Гайка М12-6H (S18)»), в 3D и спецификации — без него.

## Вставленные изделия

```python
for x in partlib.inserted():         # компоненты из методов справочника: addr, name, method, vars
    ...
r = partlib.edit(kh.obj("comp:…"), cls, {"Диаметр резьбы": 12, "Длина болта": 60, "Шаг резьбы": 1.75, "Размер под ключ": 18})
r["mode"]   # variables — тот же метод: переменные, имя, масса (сопряжения и позиция целы)
            # replaced — другой метод: новый компонент на месте старого, старый удалён с его сопряжениями;
            # ось стержня сохраняется: у методов разные локальные оси (болт 7798 — −Z, винт 11738 — +X),
            # новый поворачивается (r["axis_turned"] — какие оси совмещены)
```

Удаления в либе нет: компонент удаляется как обычный (`kh.obj(addr).cast("IFeature7").Delete()` в этапе) — его
строка спецификации уходит вместе с ним; макроэлемент чертежа — `IDrawingObject.Delete()`.

Смена исполнения с тем же файлом метода (исп 1 → исп 3 у ГОСТ 7798) — тоже `variables`.

## Чего пока нет

- Конструктивные элементы (отверстия, канавки, проточки, шлицы, шпоночные пазы — 161 класс): их методы —
  VBS, которые библиотека исполняет со своим объектом `VBGuru` и гранями позиционирования, выбранными
  человеком. Отверстия и пазы — операциями КОМПАС.
- Крепёжные наборы (TCS), «Найти и заменить», «Обновить ссылки», «Деталь на базе стандартной» и настройки
  библиотеки — команды с окнами, в адаптер не вошли.
- Правка 2D-изображения — удалить макроэлемент и вставить заново (`insert_2d` с той же точкой).
