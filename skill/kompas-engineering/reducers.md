# reducers — «Каталог: Редукторы» (Libs\Reductor)

Либа в неймспейсе скриптов: `reducers` (`from kompas_agent.libs import reducers`). Само приложение (reductor.rtw)
на машине не работает: базу оно открывает через ODBC-источник «reductor», а он указывает на 64-битный драйвер
Access, которого нет. Поэтому либа работает с данными приложения сама: каталог — из reductor.mdb (32-битная выгрузка
в кэш, `_catalog.mdb`), изображения — из библиотеки фрагментов reductor.fdb (`_catalog.lfr`, только API5), 3D-модель
(у приложения её нет) — упрощённая, по габаритам фрагментов и размерам валов из базы.

## Каталог (КОМПАС не нужен)

```python
reducers.kinds()                                   # cyl1, cyl2, cyl3, worm1, worm2 (команды 1001–1003, 2001–2002)
reducers.search('Ц2У', torque=(1000, 3000), ratio=25, aw=250, duty='Н')   # фильтр окна приложения
reducers.select(2000, ratio=25, speed_in=1500, kind='cyl', duty='Т')      # подбор → best, candidates, rejected_by
reducers.info('Ц2У-250', ratio=25, assembly='13', shaft_out='conical', climate='У2')   # всё о типе + dims
reducers.designation('Ц2У-250', 25, '12', 'У2')    # 'Редуктор Ц2У-250-25-12-У2'
reducers.lists('worm'); reducers.climates('Ч-125'); reducers.calc_motor(...)   # = elmotors.calc
```

- Момент: у цилиндрических — по режимам Н/Т/С/Л (ПВ 100/40/25/15), у червячных — по передаточному числу (таблицы
  *-param, ПВ 100/60/40/25) с мощностью на входе при 1500 об/мин.
- `aw_total` — полное межосевое (вход — выход): у многоступенчатых сумма ступеней.
- Исполнение: `ratio` (из ряда типа), `assembly` (вариант сборки из столбца sborka: 11…33, 16/26/36 — полый
  выходной вал, 51…56 у червячных одноступенчатых), `shaft_in` ('conical'|'cylindrical'), `shaft_out`
  ('conical'|'cylindrical'|'coupling'|'hollow_key'|'hollow_spline'), `climate`. Не заданное — первое доступное.
  Неверное — `ReducersError` с вариантами в `extra`.
- Цифры варианта сборки (толкование либы по ГОСТ 20373 и фрагментам; окно приложения не открывается): первая —
  конец входного вала, вторая — выходного: 1 — «к себе» на главном виде (+Z модели), 2 — обратная сторона (−Z),
  3 — оба, 6 — полый выходной вал; у червячных одноступенчатых червяк выходит вправо (+X).
- Наименование: «Редуктор <тип>-<i>-<вариант>[-Ц|М|П]-<климат>» (Ц — цилиндрические концы, М — полумуфта,
  П — полый вал); точный шаблон приложения сверить нельзя.
- Таблица «Необработанные» (7 строк) приложением не показывается — либой тоже. У 2Ц2-250Н(-нв/-нс) и 2Ч-63/100М нет
  фрагментов — только каталог (create/create_2d → `no_geometry`).

## В документе (внутри этапа)

```python
r = reducers.create('Ц2У-250', ratio=25, assembly='13', climate='У2', at=(0, 0, 0), xdir=(1, 0, 0), up=(0, 1, 0))
r = reducers.create('Ч-125', ratio=20, onto='<адрес цилиндрической грани ступицы>', out_end='+z')
reducers.place(r['addr'], at=(0, 500, 0), xdir=(0, 0, 1)); reducers.edit(r['addr'], tip='Ц2У-315НМ')
reducers.delete(r['addr']); reducers.reducers_in(); reducers.info_of(0); reducers.spec_rows()
g = reducers.create_2d('Ч-125', ratio=20, assembly='51', view=['main', 'left', 'top', 'right', 'back'],
                       at=(45, 110), scale=0.1, gap=8, hollow_sketch=False)
reducers.edit(g['items'][0]['addr'], tip='Ч-160')       # вся группа видов на том же месте
reducers.place(g['items'][0]['addr'], at=(40, 250))     # группа в новую точку
reducers.delete(g['items'][0]['addr'], group=True)      # все виды и строка спецификации
reducers.feet_2d('2ЧМ-63', view='main', at=(40, 100), scale=0.4)   # опорная лапа (lap1/2/3)
reducers.part('Ц2У-250', path=None)                     # файл детали (path=None — в кэш)
```

- 3D: локальная деталь в сборке (плита по виду сверху с отверстиями под болты, корпус по главному виду — уже
  плиты, чтобы над отверстиями под лапы было место под головку болта с шайбой: `dims.body_width`; концы
  валов: конический — цилиндр D на длине L + хвостовик, цилиндрический — D, полумуфта — диск, полый — сквозное
  отверстие). Модель: X — от выходного вала к входному (цилиндрические), Y — вверх, Z — к смотрящему на главный
  вид; начало — ось выходного вала в средней плоскости (цилиндрические) или ось червяка (червячные). Масса —
  по каталогу (МЦХ «ручное задание массы»). Описание возвращает концы валов в координатах сборки (exit/tip).
- Строка спецификации 3D — собственный объект спецификации компонента (раздел «Прочие изделия»): отменяется
  Ctrl+Z вместе с ним; `delete`/`edit` удаляют её до компонента (иначе висячий объект роняет КОМПАС при чтении
  спецификации), `spec=False` в 3D-`delete` не действует. 2D — один объект на группу видов.
- Метка компонента (IUserParameters с LibraryFileName/Command) переживает запись и переоткрытие сборки.
- `edit(tip=…)` сохраняет начало модели (ось выходного вала): у большего редуктора опорная плоскость плиты
  уходит ниже — переставьте `place(at=…)` по `dims.box.y` нового типа.
- 2D: каждый вид — макроэлемент из вставок фрагментов приложения (корпус вида + концы валов по варианту сборки;
  вид сверху — «-h»; вид сзади и справа без фрагмента «4» — зеркало главного/левого). Конец вала «назад» на боковом
  виде повёрнут на 180° (шпонка снизу).

## Чего пока нет

- Само приложение не запускается (ODBC) — его окно и точный шаблон наименования не сверены.
- 3D — упрощённая коробка корпуса (без силуэта главного вида, бобышек, крышек, лап червячных; ширина корпуса —
  условная, по отверстиям под лапы).
- create(onto=…) не проверен вживую.
- Подбор `select(ratio=…)` с числом не из ряда отвечает `best: None` (rejected_by: ratio) — ряд передаточных
  чисел типа: `info(tip)['ratios']`; без `ratio` ограничение по передаточному числу не учитывается.
- Без `climate` наименование — без климата («Редуктор Ц2У-100-16-12»).
- Отменённый Ctrl+Z create_2d оставляет строку спецификации в чертеже (КОМПАС не отменяет её) — убрать
  spec_orphans(delete=True).
- Лапы червячных — только 2D и только точкой вставки (приложение просило указать отверстия мышью).
- Червячные двухступенчатые: положение входного вала — по A и h из базы (сверено с окружностью главного вида);
  вид «4» используется как вид справа — назначение фрагмента предположено.
