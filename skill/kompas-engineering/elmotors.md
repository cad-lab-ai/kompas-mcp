# elmotors — «Каталог: Электродвигатели»

Приложение КОМПАС-3D v19 `Libs\ElMotors` (elmotors.rtw, база elmotors.mdb, библиотека фрагментов Elmotors.fdb).
**Само приложение на этой машине не работает**: базу оно открывает через ODBC-источник «ElMotors» (64-битный драйвер
Access, которого нет) — «Не найден драйвер или источник данных ODBC». Поэтому либа `elmotors` всё делает сама по данным
приложения: каталог — из базы (32-битная выгрузка в JSON-кэш), 3D — своя упрощённая модель по размерам каталога,
2D — фрагменты из библиотеки приложения или своё изображение по размерам.

## Пример

```python
elmotors.search('АИР112', power=(4, 7.5), speed=1500)          # фильтр окна приложения
elmotors.select(power=5.5, speed=1500)                           # best + candidates
elmotors.calc(force=2000, velocity=1.3, drum=300, efficiency=0.951, ratio=18)   # мастер подбора (elmcalc)
elmotors.info('АИР160S2', mount='IM1081')                        # параметры, размеры, климат, наименование
# этап на сборке
m = elmotors.create('АИР160S2', mount='IM1081', climate='У3', at=(0, 0, 0), axis=(1, 0, 0))
elmotors.create('АИРС80А2', mount='IM2082', shaft_end=(0, 0, 600), axis=(0, 0, -1))
elmotors.motors(); elmotors.place(m['addr'], shaft_end=(200, 0, 0)); elmotors.delete(m['addr'])
# этап на чертеже
elmotors.create_2d('АИРС100S4', mount='IM1081', climate='У3', view=['main', 'top'], at=(20, 150), scale=0.25)
elmotors.spec_orphans(delete=True)                               # висячие строки после Ctrl+Z create_2d
elmotors.part('АИРС100S4', mount='IM1081', path=r'C:\…\mot.m3d')   # файл детали
```

Система координат двигателя: ось вала — X (конец вала в +X), начало — на оси в плоскости заплечика вала, Y — вверх
(опорная плоскость лап Y = −h). Компонент — локальная деталь с меткой IUserParameters (LibraryName «elmotors»,
JSON; с LibraryFileName/Command — метка переживает запись и переоткрытие), строка спецификации — собственный
объект спецификации локальной детали, перенесённый в раздел «Прочие изделия» (30), наименование по шаблону
приложения. `delete`/`edit` удаляют строку ДО компонента: после удаления компонента его объект спецификации висит,
и чтение спецификации роняет КОМПАС v19; `spec=False` в 3D-`delete` не действует (строка уходит с компонентом).
2D: изображение — макроэлемент с меткой (своё — по размерам, крановые и др. — фрагмент приложения внутри
макроэлемента); одна строка спецификации на вызов `create_2d` (все виды вызова в её геометрии) — два вызова для
одного двигателя дают две строки. Без `climate` наименование — без климата.

## Покрытие

| Возможность | Функция | Вживую |
|---|---|---|
| Виды (команды 1, 2, 3, 4, 5, 20, 25), поиск по типу/мощности/частоте/высоте оси/IM | `kinds`, `search`, `lists` | да (вне КОМПАС) |
| Параметры, размеры, исполнения IM, климат, описание, изготовитель | `info`, `mounts`, `dims`, `climates` | да |
| Наименование для спецификации | `designation` | да (шаблон из rtw, порядок полей — догадка) |
| Подбор и «Мастер подбора» (мощность, частота, КПД передач, проверочный расчёт) | `select`, `calc`, `efficiency_table` | да (сверено с Elmcalc.cfg) |
| 3D-модель в сборку, размещение (at/axis/up, shaft_end) | `create` | да |
| Строка спецификации | `create(spec=True)`, `spec_rows` | да |
| Список вставленных | `motors`, `find`, `info_of` | да (3D, 2D; и после записи и переоткрытия) |
| Перестановка, смена типоразмера, удаление | `place`, `edit`, `delete` | да (3D и 2D; Ctrl+Z удаления) |
| Размещение по цилиндрической грани | `create(onto=…)` | нет |
| 2D: фрагменты приложения / своё изображение по видам | `create_2d` | да (АИРС100S4 main/top, крановый 4MTF132L6) |
| Висячие строки спецификации после Ctrl+Z в чертеже | `spec_orphans(delete=True)` | да |
| Файл детали-двигателя | `part` | да |

## Чего пока нет

- Мастер наполнения базы (addmotor.dll) — запись в базу в Program Files; не делалось.
- Масса модели не равна каталожной (подбор плотности SetMaterial в контексте не подтвердился): у АИРС100S4 —
  75 кг (сплошная сталь). Ширина корпуса модели ограничена высотой оси (d30/2 > h у малых машин).
- В базе нет АИР 71–100 (есть АИРС, АИР56, АИР112+); `not_found` подсказывает типы той же высоты оси.
- `search` отдаёт не больше `limit` (50) без признака усечения — `limit=None` для всех.
- Крановые, коллекторные, шаговые, RA — без размеров в базе: 3D нет, только 2D фрагментами.
