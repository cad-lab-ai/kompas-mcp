# weldseam — «Условные изображения швов сварных соединений» из скрипта

Либа-адаптер приложения «Условные изображения швов сварных соединений» (Libs\WeldSeam, WeldSeam.rtw) КОМПАС-3D v19:
изображения швов и катетов на чертеже и во фрагменте по ГОСТ 2.312 и ГОСТ 21.502. В неймспейсе `code_exec`, `query`,
`test_exec` — имя `weldseam` (в установленном плагине без нового host.py — `from kompas_agent.libs import weldseam`).
Создание и правка — внутри этапа, чтение — где угодно. Ошибки — `weldseam.WeldSeamError` (`code`, `message`,
`extra` — варианты, допустимые параметры).

**Важно: строится своими средствами API 2D, а не командой приложения.** Изображение — макроэлемент вида (имя — как
команда приложения: «Шов стыковой»…) из отрезков, дуг, окружностей, штриховки или заливки по формам и умолчаниям
приложения (диалог «Параметры изображений сварных швов» и его поясняющие рисунки). Двойной щелчок по нему панель
приложения не открывает — правка через `weldseam.edit`. Почему не командой — «Чего пока нет».

## Швы по линии (501–503)

```python
m = weldseam.seam("стыковой", [(0, 0), (100, 0)])               # 501, монтажный (крестики), сплошной
weldseam.seam(501, seg, mounting=False)                           # заводской (штрихи) по отрезку чертежа
weldseam.seam(502, arc, mounting=False, intermittent=True)        # угловой/тавровый, направление 1, прерывистый
weldseam.seam(503, "view:1/geom:8589934593", hidden=True, hidden_line=True, view=1)   # с невидимой стороны
```

- `path` — точки вида `[(x, y), …]` (ломаная) или объект чертежа/адрес (`view:N/geom:<Id>`): отрезок, дуга,
  ломаная, сплайн, окружность — кривая разбивается по длине. Координаты — вида (`view` — номер или IView, по
  умолчанию активный).
- `seam`, `points`, `leg`, `edit` возвращают запись как `items()`: `{ref, addr: 'view:N/geom:<Id>', cmd, kind,
  режимы, content, box, view}`; адрес переживает переоткрытие, сам макроэлемент — `kh.obj(addr)`. `info`, `edit`,
  `delete` принимают адрес, эту запись, IMacroObject или Reference.
- `mounting=True` — монтажный: крестики (параметры h1, t1, T1, S1, L1); `False` — заводской: штрихи (h, t, T, S, L).
  Умолчания у групп разные (501: L1=10, T1=5; 502/503: L1=9, T1=6) — при смене вида 501→502 общие параметры
  сохраняются, остальные берутся по умолчанию нового вида.
- Сторону 502/503 агент выбирает сам: 502 — знаки слева от направления пути (от первой точки к последней), 503 —
  справа; чтобы знаки легли на сторону детали, задайте путь так, чтобы деталь была слева (502) или справа (503).
- 501 — знаки симметрично линии; 502 — с одной стороны (слева от направления пути), 503 — с другой.
- `intermittent` — прерывистый: участки длиной L через промежуток S; `hidden` — с невидимой стороны: группы
  знаков длиной T через T; `visible_line` / `hidden_line` — рисовать саму линию шва (сплошную / штриховую).
- Размеры знаков — в мм листа (`sheet_mm=True`): на виде 1:2 штрихи в координатах вида вдвое длиннее.

## Точечные (504–506)

```python
weldseam.points(504, path=[(0, -80), (100, -80)], step=15)   # внахлёстку контактный точечный, шаг 15 (по умолч. 10)
weldseam.points(505, at=[(20, -100), (50, -100)], hole=True) # электрозаклёпочный, точечный режим, с отверстием
weldseam.points(506, at=[(70, -100)])                         # сварные точки: «+» размера H
```

Режим шва — `path` + `step` (точки через шаг, первая на полшага от начала); точечный режим — `at` (знаки повёрнуты
на `angle`°). 504: залитая точка D в разомкнутом ромбе H и оси; 505: «Z» высотой H, отверстие D, оси.
Больше 10000 точек — ошибка, как у приложения.

## Катет (507–509)

```python
weldseam.leg(507, lines=(seg1, seg2), A=5)                          # со скруглением внутрь, по двум линиям
weldseam.leg(508, points=[(120, 0), (140, 0), (120, 20)], equal=False, A=8, B=5)   # наружу, по трём точкам
weldseam.leg(509, lines=(l1, l2), fill="Заливка")                   # без скругления, залитый треугольник
```

`lines` — отрезки или прямые: вершина — их пересечение (продолженных), стороны — к дальним концам; `points` —
вершина, точка на стороне 1, точка на стороне 2. `equal` — равносторонний (A, A), иначе A по стороне 1, B по
стороне 2. Скругление — дуга через концы катетов и точку под 45°. `fill` — Штриховка | Заливка | Нет,
`segments` — рисовать стороны катета. A, B — в единицах вида (катет — размер на детали).

## Чтение, правка, удаление

```python
weldseam.items()        # [{ref, addr: 'view:N/geom:<Id>', cmd, kind, mounting, …, content, box, view}]
weldseam.info(addr)     # + params, path / at / corner, d1, d2
weldseam.edit(addr, mounting=False, h=3)          # → запись с новым адресом, replaced — прежний
weldseam.edit(addr, katet=3)                      # bad_param: у вида нет параметра (как у seam)
weldseam.edit(addr, kind=508, A=10)               # вид в своей группе: 501↔502↔503, 507↔508↔509, 504↔505↔506
weldseam.delete(addr)
weldseam.defaults(501); weldseam.parameters(507); weldseam.commands()
```

Параметры построения хранятся в метаданных макроэлемента (`IPropertyKeeper.Properties`, свойство `weldseam`):
переживают сохранение и открытие файла, отмена этапа их откатывает. Изображения, построенные самим приложением
(человеком), `items` не видит.

## Чего пока нет

- **Объект самого приложения.** Команда 501–509 строит изображение на указаниях в окне; первая точка/линия щелчком
  (PostMessage, `ui.run(steps=[{'pick': отрезок}])`) принимается, вторую (свободную) точку команда берёт по
  положению курсора — при заблокированном экране / отключённом RDP её не указать (`desktop` в ответе). Ввод координат
  в поле «Положение точки» (тип ksControlEditPoint) движок `_appui` не умеет. Поэтому изображения строятся своими
  средствами: состав (отрезки, дуги, штриховка) — по рисункам диалога приложения, но с объектом приложения
  **не сверено** (образца, построенного приложением, получить не удалось): толкование букв (h — от линии шва до
  конца штриха, T — промежуток групп «невидимой стороны», L/S — участок и промежуток прерывистого шва), сторона
  направления 1/2, точная форма знаков 504/505 и стиль штриховки катета — по рисункам, могут отличаться.
  Возможный прямой путь (не проверен): обработчику процесса библиотеки (`ksProcess2DNotify.PlacementChange(x, y,
  angle, False)`) — нужен перехват создания процесса в `_appui`; или сеанс с экраном.
- **Пользовательские умолчания** (WeldSeam.cfg, пишет диалог 217) не читаются: формат не разобран — используются
  заводские умолчания v19 (`DEFAULTS`); свои значения — параметрами вызова.
- Двойной щелчок по изображению либы панель приложения не открывает; характерных точек нет.
- Изображения, построенные приложением, `items/info/edit` не разбирают (формат их параметров неизвестен).
