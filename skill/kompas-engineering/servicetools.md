# servicetools — «Сервисные инструменты» из скрипта

Либа-адаптер приложения «Сервисные инструменты» (Libs\ServiceTools, komlib.rtw, «Прикладная библиотека КОМПАС»)
КОМПАС-3D v19: 2D-инструменты чертежа и фрагмента. В неймспейсе `code_exec`, `query`, `test_exec` — имя
`servicetools` (в установленном плагине без нового host.py — `from kompas_agent.libs import servicetools`).
Создание и правка — внутри этапа, чтение (`holes`, `info`) — где угодно. Работает в документе вызова (цель этапа);
координаты — вида (`drawing_view` — номер вида, по умолчанию текущий). Адреса объектов — `view:N/geom:<Id>` (как в
diff/find), принимаются и объекты, и `obj2d:<ref>`. Ошибки — `servicetools.ServiceToolsError` (`code`, `message`,
`extra` — варианты, подробности).

Как сделано: отверстия и резьба — **объекты самого приложения** (его команда, поля его панели; положение — полем
«Базовая точка» с фиксацией, без мыши); правка по выделению — **команда приложения** по выделенным объектам внутри
вызова; построения по объектам — **команда приложения** с указанием объекта щелчком оконным сообщением (работает и
при заблокированном экране; окно само наводится на нужное место); где команда приложения указание не принимает —
**своими средствами API** по тому же правилу (выравнивание, продление/усечение).

## Отверстия и резьба (49–53, 76)

```python
h = servicetools.hole((50, 20), d=10, depth=30, angle=-90)               # простое, ось вниз от точки
servicetools.hole((0, 0), "csink", d=6.6, depth=20, csink={"d": 12, "angle": 90}, angle=-90)
servicetools.hole((40, 0), "cbore", d=6.6, depth=20, cbore={"d": 11, "depth": 6.8}, view="top")
servicetools.hole((80, 0), "csink_cbore", d=5, depth=15, cbore={"d": 10, "depth": 3}, csink={"angle": 60})
servicetools.hole((120, 0), "conic", d=4, depth=12, cone={"angle": 7.5}, bottom="sphere")
servicetools.hole((160, 0), d=10, depth=25, thread={"d": 12, "length": 18})   # резьбовое M12, резьба 18 мм
servicetools.thread((200, 0), d=16, angle=90, axes=False)                     # наружная резьба M16
servicetools.thread_standards()                                               # список «Стандарт»
```

- `at` — базовая точка (x, y) вида; `angle` — угол оси отверстия к оси X вида (0 — вправо, -90 — вниз).
- `kind`: `simple` | `csink` (зенковка) | `cbore` (цековка) | `csink_cbore` | `conic` (или номер 49–53, русские имена).
- `view`: `side` | `top` (вид сбоку / сверху); `style`: `visible` | `hidden` | `thin`; `axis` — ось;
  `bottom`: `cone` (угол `bottom_angle`, 120) | `flat` | `sphere` | `through`.
- `csink` — два из `d`, `depth`, `angle` (как «Способ» панели); у `csink_cbore` — только `angle`, диаметр и
  глубина — `cbore`. `cone` — `{'d': диаметр основания}` или `{'angle': угол конуса}`.
- `thread=True | {'standard', 'd', 'pitch', 'length'}` (`length` None — на всю глубину); у резьбового отверстия
  `d` = номинал резьбы. Резьба: `d`, `pitch` (None — по стандарту), `standard`, `style`, `rod` (стержень), `axes`.
- Незаданное — умолчания приложения v19 (панель помнит прошлые значения — либа ставит умолчания явно).
- Ответ (и `info`): `addr`, `at`, `angle`, `kind`, `d`, `depth`, `view`, `style`, `axis`, `bottom`, `csink`, `cbore`,
  `cone`, `thread` — прочитаны из объекта (`IUserParameters.UserParams` приложения), `drawing_view`.

```python
servicetools.holes()                         # все отверстия и резьбы документа (drawing_view=N — одного вида)
servicetools.info(addr)
new = servicetools.edit(addr, d=12, kind="cbore", cbore={"d": 20, "depth": 5}, at=(10, 10), angle=0)
servicetools.delete(new["addr"])
servicetools.rebuild_holes()                 # 56 «Перестроить отверстия и изображения резьб»
```

`edit` перестраивает объект командой приложения с прежними + новыми параметрами на том же месте и удаляет старый —
**адрес новый** (`replaced` — старый). Вложенные `csink`/`cbore`/`cone`/`thread` заменяются целиком.

## Правка по объектам (39, 41–43, 58–68, 69–75)

```python
servicetools.rotate([a, b], 90)                  # группой на 90° влево (62); -90 — вправо, 180; group=False — каждый (59–61)
servicetools.mirror([a, b], "vertical")          # относительно вертикали через центр габарита группы (68); каждый — group=False
                                                 # (v23: 67/68 приложения ничего не делают — группа отражается 65/66 + сдвигом, via)
servicetools.align([c1, c2], "left", (400, 0))   # left|right|top|bottom|middle_v|middle_h|center — по точке
servicetools.hide([obj])                         # 39: на новый погашенный слой → {layer}
servicetools.fill_to_hatch([fill])               # 58: заливка → штриховка (и штриховка → заливка) → {created}
servicetools.closedness()                        # 41 все объекты; main_style_only=True — 43; closedness(objs) — 42
#   → {breaks: [[x, y]…], points: [адреса точек «Круг»], closed}; keep_points=False — точки убрать
```

## Построения по объектам (23, 37, 38, 46, 47, 48)

```python
servicetools.similar(seg, 7, side=(0, -60))          # 38 подобие с одной стороны (точка — с нужной стороны)
servicetools.similar(arc, 5, both=True)              # с двух сторон
servicetools.extend_trim(s1, s2, at2=(160, 10))      # 37: до пересечения, at — остающаяся часть
servicetools.contour_boundary((25, 25))              # 48: контур замкнутой области вокруг точки
servicetools.contour_boolean(c1, c2, "subtract", delete_source=True)   # 47: union | subtract | intersect
servicetools.approximate_curve(ellipse, tolerance=0.2, max_radius=50)  # 23: кривая → дуги и отрезки (контур)
servicetools.approximate_contour(contour, kind="polyline", tolerance=0.5)  # 46: контур → ломаная | сплайн
```

`approximate_curve`/`approximate_contour` по умолчанию **удаляют исходный объект** (`delete_source=True`, как флажок
команды): адрес эллипса/контура после вызова недействителен, результат — `created`. Оставить исходный —
`delete_source=False`.

Ответ построений — `{created: [{addr, kind, box}]}`. Объект указывается щелчком: если вдоль всего объекта рядом
другие (контур поверх совпадающих отрезков) — `pick_failed`: удалите/скройте совпадающие.

## Чего пока нет

- **24 Замена текста, 27 Выделение размеров с ручным вводом, 40 Ассоциирование размеров, 26 Экспорт спецификации,
  22 Спецификация → фрагмент, 34 Числовые колонки спецификации, 25 МЦХ профиля, 55 Отверстие по шаблону,
  99 Настройки** — функций верхнего уровня нет (не хватило времени агента). Все — своё окно приложения: путь —
  `servicetools.ui.run(cmd, window=…)` / инструмент `dialog` (24 в s38 доведена: «Найти»/«Заменить на» → OK).
  25 после окна ждёт точку внутри области — `contour_boundary`-подобное указание (`steps=[{'pick': [x, y], 'blind':
  True}]`).
- **57 Заливка → штриховка по образцу, 77/45 Символы вдоль кривой** — нет. 77: кривая указывается, текст вводится в
  окне «Введите текст» (свой редактор КОМПАС; ввод — только фокусом извне: AttachThreadInput + WM_CHAR, проверено
  руками), но после OK «Создать» осталась недоступной — не доведено.
- 37 и 69–75 — не командой приложения: 37 щелчки по объектам не принимает (и при отложенном запуске), 69–75 берёт
  базовую точку только щелчком без панели (внутри вызова модальный цикл висит). Сделано по правилу справки своими
  средствами; 37 — отрезки и дуги (окружность — только граница), эллипсы не поддержаны.
- Отверстие/резьба «на кривой» (поле «Объект», «По нормали») — не выведено в параметры.
- Проверено во фрагменте и в чертеже с видом масштаба 1:2 (`drawing_view`: отверстия, правка, резьба).
- Адреса: ответы либы — `view:N/geom:<Id>`, а `diff`/`effect` плагина — `obj2d:<ref>`; либа принимает оба.
  Во фрагменте `effect` показывает только созданные/удалённые объекты — изменение (`extend_trim`, `rotate`,
  `align`) проверяйте по ответу либы (`box`, `info`).
- `angle=-90` читается обратно как 270 (то же направление).
