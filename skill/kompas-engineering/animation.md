# animation — «Механика: Анимация» (Libs\Animation3D\Animat.rtw)

Анимация сборки: сценарий из шагов (вращение вокруг осей, перемещение по ломаной/сплайну или формуле, переменные,
прозрачность, соударения), воспроизведение, видео. В неймспейсе `code_exec`/`query`/`test_exec` — `animation`.

Три слоя:
1. **Сценарий** — XML-файл приложения (его «Загрузить» читает файлы либы, либа читает его файлы). Правка — без КОМПАС
   (`Scenario`), с проверкой по сборке (функции ниже).
2. **Своё воспроизведение** через API (`play`) — без окна: положения по кадрам, соударения, траектории точек, кадры
   PNG, AVI. Двигает модель → `test_exec` (откат сам) или этап; `restore=True` по умолчанию возвращает всё.
3. **Само приложение** на сценарий (`app_play` / `app_status`) — окно, «Загрузить», «Настройки», «Воспроизведение»,
   закрытие; без мыши (WM_COMMAND, таймер UI-потока).

```python
sc = animation.new(frames=24)                                     # шаг 1 пустой
animation.move(sc, 1, 'Вал', path='Траектория вала', time=2)      # ломаная сборки по имени дерева
animation.rotate(sc, 1, 'Вал', axis='Ось вала', angle=720, freq=(60, 'об/мин'))
animation.collisions(sc, 1, ['Вал'])
n = sc.add_step(comment='вниз', scene_time=0.5)
animation.move(sc, n, 'Вал', formula=('const', 'const', '-10*t'), time=2)
animation.move(sc, n, 'Упор', offset=(0, 0, 40), speed=(20, 'мм/сек'))
animation.transparency(sc, n, 'Упор', 0, 0.7, time=1)
animation.check(sc); sc.info(); sc.save(r'…\сценарий.xml')
r = animation.play(sc, points=[{'comp': 'Упор', 'point': [20, 5, 10]}], track=6,
                   capture={'dir': r'…\кадры', 'camera': 'iso', 'size': 600}, video=r'…\ролик.avi')
# r: steps[{step, t, moved{имя#номер: from, to, shift_mm, turn_deg}, track}], collisions[{step, t, a, b, kind}],
#    trajectories{метка: [[t, x, y, z]…]}, images, video, final, restored
animation.app_play(r'…\сценарий.xml')        # в этапе (code_exec): приложение двигает модель
animation.app_status(wait_s=30)              # следующим code_exec — итог, лог шагов драйвера
```

- Скорость: `speed=(v, 'мм/сек' | 'мм/с' | 'м/сек' | 'м/с' | 'км/час' | 'км/ч' | 'узел')` или число мм/сек; частота —
  `freq=(v, 'гц' | 'об/мин')` или число Гц. Неверная единица → `bad_unit` со списком допустимых.
- Имена осей и траекторий либа пишет в файл так, как они в дереве: у осей сборки часто ведущий пробел
  (`axes()` → `' Ось клапана'`), в файле это `"_Ось_клапана"`. Писать имя можно без пробела — либа подставит точное.
  `check()` сверяет посимвольно: файл с `"Ось_клапана"` (без «_» впереди) → `axis_name`, приложение такой не
  загрузит («Encountered an improper argument»).
- `app_play` запускает приложение **после** вызова (команда идёт из главного цикла КОМПАС): пока вызов не вернулся,
  окна нет. `app_status` в том же вызове ответит `waiting` — зовите его следующим вызовом. Пути сценария и видео
  можно с прямыми слэшами (либа приводит к `C:\…`).
- `spread(sc, step, src, comps, what='move'|'rotate')` — то же движение компонента `src` для списка `comps`.
- `play(collisions=True)`: пары, пересекающиеся уже в начале шага (натяг собранной модели), соударением не считаются
  и не останавливают `stop_on_collision` — они в `initial_intersections` (`ignore_initial=False` — считать всё).
- `moved[…].turn_deg` — итоговый поворот (между началом и концом шага): 360° и 1440° дают 0; полный угол — в
  `sc.info()` шага.

## Покрытие (меню приложения → либа)

| Возможность приложения | Функция | Вживую |
|---|---|---|
| Создать / Загрузить / Сохранить / Сохранить как | `new`, `load`, `sc.save` (формат приложения) | да (01.xml образца, файлы либы — с ломаной и с вращением — грузятся окном) |
| Настройки: кадров/с, пауза, перестроение, цикл | `sc.settings(frames, pause, rebuild, cycle)` | да (Rebuild читается окном; Cycle окно при загрузке не включает) |
| Настройки: видео, кинограмма, останов при соударении | `app_play(video=, kino=, stop_on_collision=)`; своё — `play(video=, stop_on_collision=)` | своё — да; видео приложением — да (несжатый AVI по умолчанию: ~50 МБ/с ролика); кинограмма — нет |
| Шаги: добавить, копировать, удалить, вверх/вниз, перенумеровать | `sc.add_step`, `copy_step`, `delete_step`, `move_step` (нумерация сама) | XML — да |
| Добавить инвертированные шаги | `sc.add_inverted()` | XML — да, воспроизведение — нет |
| Комментарий и время подготовки сцены | `sc.comment(n, text, scene_time)` | да (окно показывает) |
| Запомнить / установить начальное состояние | `remember_state`, `reset_to_start` | XML-формат с образца приложения; reset — нет |
| Отключить сопряжения шага | `mates_off(sc, n, [индексы])`; `play(mates='step'|'free'|'keep')` | формат с образца; в play — не проверено на конфликтующих сопряжениях |
| Выбрать компоненты (дерево/модель), все, исключить | `add`, `add_all`, `remove` | да |
| Перемещение: траектория (ломаная/сплайн), формула, из начального в текущее, распространить, удалить | `move(path= / formula= / offset=)`, `from_start`, `spread`, `remove(what='move')` | ломаная и формула — да (сверено с приложением); spread/from_start — нет |
| Построить траекторию (считывать положения) | нет — постройте ломаную API (ksPolyLineDefinition) и `move(path=…)` | — |
| Вращение: ось, распространить, удалить | `rotate(axis=, angle, time | freq)`, `spread(what='rotate')` | да (направление сверено с приложением; файл либы с вращением приложение грузит и играет) |
| Переменные | `variable(sc, n, 'L', stop, start, time)`; play меняет и перестраивает | своё — да; **приложение** на файле либы даёт NaN (формат времени переменной не угадан) |
| Прозрачность | `transparency` | XML — да; play ставит цвет детали, в кадрах (копия C3D) не видно |
| Соударения | `collisions`; `play(collisions=True|[…], touch, stop_on_collision)` | да (формат с сохранения приложения, своё — kh.intersection по кадрам) |
| Траектория точки | `play(points=[{'comp', 'point'} | адрес вершины])` → координаты по времени | да (comp+point); в XML (Points) — нет: формат неизвестен |
| Воспроизведение шага / полное | `app_play(step=n)` / `app_play()`; своё — `play(steps=n)` | полное — да, шага — нет |
| Видео AVI | `play(video=…)` (MJPEG из кадров) | да (файл AVI валиден) |
| Возврат в исходное состояние | `play(restore=True)`; этап — `change_abort` | да |

Чтение сборки: `components()` (номер = Number сценария), `curves()`, `axes()`, `variables()`, `mates()`,
`curve_points`, `axis_line`; `positions(sc)` — положения по времени без движения модели.

## Семантика (сверено воспроизведением самого приложения)

- Number компонента — индекс в сборке (ksPartCollection, тот же порядок, что `Parts`); Name сверяется (`component_mismatch`).
- Ломаная: сдвиг на (v_k − v_0) по длине пути; Direct=1 вперёд, -1 назад; **Direct=0 приложение не двигает**.
- Формула `X=…#Y=…#Z=…`: сдвиг от начала шага, t — секунды, const — 0; приложение делает лишний кадр (Вал −10,417 вместо −10).
- Вращение Direct=1 («по часовой») — +угол по правилу правой руки вокруг направления оси.
- Время всегда пишется Type=1 (секунды); скорость/частоту либа пересчитывает во время: Type=0 со скоростью приложение
  в пробе не воспроизвело.
- **Fix шага обязателен**: без него приложение снимает фиксацию со всех компонентов (зафиксированная втулка повернулась
  вслед за валом по сопряжению). `add`/`move`/`rotate` пишут Fix и Mate из модели.

## Грабли приложения

- Команды с указанием в модели (компоненты, ось, траектория, вершина, соударения) оставляют вложенный цикл выбора:
  окно глохнет, Execute не возвращается — спасает только перезапуск КОМПАС. Либа их не зовёт.
- После «Сохранить как» приложения окно перестаёт слушать команды — XML пишет либа.
- Приложение создаёт в сборке свои объекты (ось «Axis11» по грани, ломаная «LineVertex…», переменная «ind») и меняет
  детали (прозрачность → «модели с несохранёнными изменениями»). Пользуйтесь им в этапе; лишнее — `change_abort`.
- Переменная из файла либы у приложения становится NaN (`-nan(ind)`) — для переменных пользуйтесь `play`.
- «Добавить все компоненты» + «Формула» уронили КОМПАС.
- После закрытия КОМПАС иногда показывает «Документ, открытый только для чтения, не может быть сохранён» — драйвер
  закрывает его сам.

## Чего пока нет

- Траектория точки и деформация (Points, Deform/Var) в XML — формат не выяснен (нужны указания мышью, которые вешают окно).
- Формат времени переменной для самого приложения (NaN).
- Кинограмма самим приложением (флажки ставятся, не проверено).
- Прозрачность в кадрах `play` (растр копии без цветов деталей).
- Оси, лежащие в двигающемся на предыдущих шагах компоненте, в `positions` берутся из текущей модели.
