# easysteel — «Оборудование: Металлоконструкции» из скрипта

Библиотека-адаптер приложения EasySteel КОМПАС-3D v19 (профили, пластины, рёбра, отверстия, болты, обработки, ведомость, спецификация, чертежи, DSTV). В неймспейсе `code_exec`, `query`, `test_exec` — имя
`easysteel`. Каталог и чтение — в любом канале; создание и правка — внутри этапа (`code_exec`).

## Каталог сортамента

```python
easysteel.find("уголок 8509")                 # {total, sortaments: [{id, title, shape, buildable, sizes}], not_buildable?}
easysteel.find("", shape="ibeam")             # все двутавры, которые либа строит
easysteel.sizes("Двутавр нормальный (Б) по ГОСТ 26020-83", {"h": 200})   # {sortament, total, sizes: [{name, p…}]}
easysteel.size(1516, "110x7")                 # {name, id, p: {b, h, t, r1, r2…}, mass_m, area_cm2}
easysteel.contour("Уголок равнополочный по ГОСТ 8509-93", "110x7")      # контур сечения, площадь
easysteel.materials("С345")                   # [{mark, standard, density}] — из Sys\MaterialData.loa
```

- Источник — база приложения `BreezeDB\BREEZE_PMS.FDB` (1625 таблиц, 63 тыс. типоразмеров). Первый вызов
  читает её отдельным процессом (~9 с) в кэш `%LOCALAPPDATA%\KompasAgent\cache\easysteel_catalog_v<NN>.json` (NN —
  версия установки, из которой база). В v23 BreezeDB и `Sys\MaterialData.loa` нет (сортамент приложения — в
  «ПОЛИНОМ:MDM»): база и материалы берутся из другой установленной версии КОМПАС; откуда — `catalog.source()`.
- Сортамент — id из `find` или название (одинаковые таблицы «полного/сокращённого/специального» каталогов
  сводятся к полному). Неоднозначно — `ambiguous_sortament` с кандидатами; нет размера — `no_size` со списком.
- `shape` — форма сечения, которую либа строит: angle, angle_bent, channel, channel_slope, channel_bent, ibeam,
  ibeam_slope, tee, rect_tube(_ri/_sharp), pipe, round, square, rect, hex (48 тыс. типоразмеров; гнутые замкнутые
  ГОСТ 30245 и трубы квадратные ГОСТ 8639 — rect_tube, площадь сечения = каталожной). `buildable: false`
  (`shape: null`) — составные сечения (коробки, спаренные), гнутые профили особой формы и т. п.: `profile()` их не
  строит (`no_shape`); в ответе `find` такие помечены, их число — `not_buildable`. Берите `buildable: true`.

## Профиль

```python
o = easysteel.profile("Уголок равнополочный по ГОСТ 8509-93", "110x7", start=(0, 0, 0), end=(0, 0, 1000))
o = easysteel.profile("Двутавр нормальный (Б) по ГОСТ 26020-83", "20Б1", start=p1, end=p2,
                      material="С345", point=2, up=(0, 0, 1))
o = easysteel.profile("Швеллер с параллельными гранями полок по ГОСТ 8240-97", "20П", curve=отрезок_или_ребро)
o = easysteel.profile("Уголок равнополочный по ГОСТ 8509-93", "110x7", start=(0, 300, 0), direction=(1, 0, 0), length=1200)
easysteel.info(o)    # сортамент, размер, материал, обозначение, point/angle/offset, длина, переменные, опоры
```

- Профиль — настоящий объект EasySteel (пользовательский объект 584): тело строит приложение, имя тела
  «Профиль@/Уголок $b 110x7 ГОСТ 8509-93;С235 ГОСТ 27772-2015$@/L = 1000 мм», масса по плотности материала.
- `start`/`end` — (x, y, z) (либа создаёт точки модели) или объекты/адреса (точка, вершина). `curve` — отрезок
  3D, ребро (проверено на отрезке 3D; ребро каркаса — в образцах ASCON).
- Положение сечения: `point` 1…9 — через какую точку сечения идёт ось (1–3 низ, 4–6 середина, 7–9 верх);
  `angle` — поворот, °, правый винт вокруг направления start→end; `up=(x, y, z)` — направить высоту сечения
  (ось Y) туда, угол считается сам (проверено на 6 направлениях); `offset=(dx, dy)` — сдвиг в осях сечения ДО
  поворота. Оси сечения при angle — `easysteel.section_frame(start, end, angle)` (правило приложения проверено
  на 14 направлениях; строго вертикальный вверх профиль — особый случай: X сечения = X модели).
- `point` и `offset` откладываются в осях сечения (X — поперёк, Y — высота), а не модели: без `up` «верх»
  сечения может смотреть вниз — направление высоты задавайте `up=`.
- Совпавшие start и end — ошибка `zero_length` (приложение построило бы профиль 7 м в стороне).
- Материал по умолчанию — из таблицы (обычно С235 ГОСТ 27772-2015). `materials("С345")` может дать и
  ГОСТ 27772-88 — для профиля берите стандарт, как у таблицы (ГОСТ 27772-2015).

## Правка

```python
easysteel.items()                                    # [{n, addr, name, kind, cmd, size, standard, material, length}]
easysteel.edit("op:…", size="26Б1", material="С255", angle=90)   # сортамент/размер/материал/положение
easysteel.edit("op:…", up=(0, 0, 1))                 # высоту сечения — вверх (как в profile)
easysteel.set_length("op:…", 1500)                   # профиль по двум точкам модели: двигает конечную точку
easysteel.params("op:…")                             # переменные любого объекта EasySteel [{i, name, value}]
easysteel.set_params("op:…", {3: 20})                # пластина: толщина 12 → 20 (обозначение «Лист d20» тоже)
easysteel.delete("op:…", with_points=True)            # → {deleted, spec_rows_deleted, also_deleted?}
```

- `set_length` в v23 не двигает точку, а ставит в опору профиля новую точку модели (прежнюю удаляет, если на неё
  больше ничего не ссылается): сдвиг опорной точки профиля в v23 ронял КОМПАС при закрытии документа. Не двигайте
  опорные точки профиля EasySteel в v23 и своим кодом (`point.X = …; Update()`) — меняйте опору.
- Толщина пластины (переменная 3) и ребра (1) через `set_params` идёт через `plate_edit`/`rib_edit`: вместе с
  обозначением «Лист d…» и строкой спецификации; выражение в ней — ошибка (только число).
- `delete` снимает строки спецификации тел объекта (висящая строка без тела роняет КОМПАС при чтении
  спецификации) и сообщает обработки, которые КОМПАС удалил вместе с объектом (`also_deleted`: разделка, где он
  формообразующий).

- Объект задаётся адресом `op:…` (из `items`/diff), самим объектом, номером в `items()` или именем в дереве.
- Металлоконструкция — тела одной детали: пересечения нового/изменённого профиля с остальными ловит `change_end`
  (пары по габаритам, касание по грани — не нарушение); правите существующий профиль — его `op:…` в `intent`,
  тогда перекрытие, бывшее до этапа, — `preexisting`, а не `unknown_pairs`. Зазор/пересечение двух объектов —
  `kh.min_distance("op:…", "op:…")`, `kh.intersection(...)` (по телам объектов; `body:…` тоже).
- Созданные либой объекты (`profile`, `plate`, `rib`, обработки) — `str(o)` даёт адрес `op:…` (в `kh.memo`, ответ
  `result`, `inspect`/`find` — как есть), `repr(o)` — интерфейс, имя и адрес.
- Длина (`info`, `items`, `length`, `parts`, `statement`) — по факту: из имени тела («L = … мм», пишет приложение,
  с его обработками), а у прямого профиля, укороченного вырезом КОМПАС по телу (вырез вращением/выдавливанием с
  областью «тело профиля»), — по геометрии тела; имя тела и строка спецификации по нему остаются номинальными —
  `length_nominal` (в `statement` — `length_nominal_mm`, `by_geometry`, `note`).
- Переменные профиля: [служебная, offset_x, offset_y, angle, point]; служебную не менять — объект ломается.
- У пластины (вариант по размерам) переменные: [служебная, ширина, длина, толщина, …].

## Пластина, ребро жёсткости

```python
p = easysteel.plate(200, 400, 12, origin=(0, 0, 0), normal=(0, 0, 1), xdir=(1, 0, 0), point=5, side="+",
                    material="С345")                      # лист ГОСТ 19903-2015 в пространстве
easysteel.plate_edit(p, thickness=20, width=150, origin=(100, 100, 100), normal=(0, 1, 0))
r = easysteel.rib([грань_стенки, грань_полки], shape="triangle", thickness=8, dims={"a": 45, "b": 90, "c": 10},
                  position="center", offset=0, side="mid")
easysteel.rib_edit(r, thickness=12, dims={"a": 40}, offset=100)
```

- `plate(width, length, thickness, …)`: длина — вдоль xdir, ширина (первый аргумент) — вдоль normal × xdir, толщина — в сторону normal (side '+'; '-' —
  обратно; 'mid' — симметрично). point: 5 — центр в origin; 1, 4, 7 — origin у конца +X (пластина уходит в −X);
  3, 6, 9 — у конца −X; 1–3 — у края −Y, 7–9 — у края +Y. angle — поворот вокруг нормали. Обозначение «Лист tN …»
  и материал правятся вместе с толщиной. Положение правится только у пластины без опор (созданной этой либой).
- Ребро: опоры — 2 грани (полка и стенка; rect3 — 3: полка, стенка, противоположная полка). Формы и размеры:
  polygon (a — катет вдоль 2-й грани, b — вдоль 1-й, c, d, e — срезы), triangle (a, b, c), rect (L1, a, c),
  rect3 (a, c; высота — между полками). position — center | end | start вдоль линии стыка граней, offset — сдвиг
  (у start положительный offset уводит ребро за край полки, у end — внутрь: проверяйте габарит в effect).
- Имя в дереве («Пластина 20x400x400», «Ребро жесткости 10»), данное либой, plate_edit/rib_edit обновляют.

## Отверстия и болты

```python
h = easysteel.holes([грань_накладки, грань_стенки], 22, at=(450, 12.8, 30), rows=2, cols=2, row_pitch=60,
                    col_pitch=80)                         # ~25 с: команда приложения + переменные
easysteel.info(h)["holes"]                                # [[x, y, z, Ø]] — проверка положения
b = easysteel.bolts(h)                                     # М — по отверстию, длина — по пакету (измеряется)
easysteel.fasteners("bolt", "22353", 20)                   # каталог крепежа приложения (Fastenings)
```

- Группа отверстий хранит снимок тела — её строит само приложение: либа запускает команду «Группа отверстий»
  (указание граней щелчком в окне документа — окно КОМПАС не сворачивать), затем задаёт размеры переменными.
  Отверстия идут только через тела указанных граней: для болтового пакета укажите грани всех деталей.
  at — точка первого отверстия на грани (решается тремя пробами); иначе d1, d2 — от опорных рёбер приложения.
  row_pitch — шаг вдоль опорного ребра 1, col_pitch — вдоль ребра 2 (направления проверяйте по info()["holes"]).
  Шаг только > 0 (`bad_pitch`); направление рядов — знак angle (90 / −90). Сетка вышла за грань — либа сама
  пробует angle обратного знака; не помещается и так — `holes_outside`, объект удалён. `holes` перестраивает
  модель — `info(h)` сразу показывает новые отверстия.
- Болтовое соединение: болт ГОСТ 22353-77, гайка ГОСТ 22354-77, шайбы ГОСТ 22355-77 (другие стандарты каталога в
  блок пока не пишутся). Пакет измеряется по стенкам отверстия (или package=), длина — наименьшая из ряда:
  пакет + 2 шайбы + гайка + 2 шага (или length=). Шайбы и гайку по пакету ставит приложение.

## Обработки командами приложения

Блоки этих объектов хранят снимок тела — их строит само приложение: либа запускает его команду (общий движок
`libs/_appui`), указывает объекты щелчком в окне документа (PostMessage, работает и при заблокированном экране; окно
КОМПАС не сворачивать), заполняет поля панели и жмёт «Создать». ~10–15 с на вызов, только внутри этапа. На время
команды системные плоскости скрываются (иначе щелчок по грани брал «Плоскость ZY»), после — возвращаются.

```python
c = easysteel.cut(профиль, грань_или_плоскость, side=2, gap=5)        # отсечь (или удлинить до непересекающей)
easysteel.cut_many([п1, п2], грань, side=1)                            # группа профилей одной поверхностью
easysteel.cut_edit(c, 10)                                             # зазор
L = easysteel.change_length(профиль, start=50, end=-300)              # отступы от концов образующей
easysteel.change_length_edit(L, end=-200)
easysteel.joint_cut([подрезаемый], формообразующий_профиль, gap=2)    # стыковая разделка (профиль удлиняется)
easysteel.angle_cut([п1, п2], gap=2, close=False)                      # угловая (профили с общими концами)
easysteel.positions(пластина)    # [{'name': 'corner1'…, 'xyz'}]; профиль: start_top, start_bottom, …, end_right
easysteel.fillet(пластина, ["corner1", "corner3"], 25)               # скругление (несколько точек — один объект)
easysteel.chamfer(профиль, "end_top", 15)                             # по стороне и углу 45°; angle=30
easysteel.chamfer(пластина, "corner2", 20, length2=40)                 # по двум сторонам
easysteel.groove(пластина, "corner4", 30, 20, shape=2, radius=5)      # паз: 1 прямоуг., 2 со скруглением, 3 с отверстием
easysteel.plate_on_face(грань, 6, symmetric=False, name="Накладка")    # лист по контуру грани (с отверстиями)
easysteel.belt(грань, thickness=8, width=50, direction="V", offset=40) # поясок жёсткости
easysteel.copy_to([профиль, пластина], [(0, 600, 0), (0, 1200, 0)])    # копии в точки → новые объекты
easysteel.split_plate(пластина, [грань_профиля])                      # «Разбить пластину» (условное деление)
```

- Числа готового объекта правятся переменными (`set_params`; `info` показывает их по смыслу): отсечь — [служ., gap];
  изменить длину — [служ., start, end]; разделки — [служ., gap]; скругление — [служ., R]; фаска — [служ., L1,
  угол | L2] (режим задан при создании); паз — [служ., L1, L2, R | D]. Пластина по грани и поясок переменных не
  имеют — правка: удалить и построить заново.
- Позиционирующие точки (`positions`) — углы пластины на лицевой стороне и середины сторон габарита сечения на
  торцах профиля; либа перед каждым щелчком поворачивает вид на точку снаружи. Можно дать и свою точку (x, y, z).
  Неудача (точка не та, размеры не помещаются) — `ui_failed`, пустой объект удаляется.
- Поля «Сторона 1/2», «Зазор», «Симметрично» приложение помнит от прошлого вызова — либа задаёт их всегда.
- `cut`: граница — ПЛОСКАЯ грань тела. side — какая часть профиля остаётся (1 — со стороны наружной нормали
  грани, 2 — за ней); при удлинении (поверхность не пересекает профиль) конец ставится на gap ЗА поверхностью —
  уголок входит в стенку на gap; нужен зазор до стенки — удлиняйте change_length.
- Непрямая грань (цилиндр пояса-дуги, труба, конус…) — отказ `curved_surface` до команды: приложение по такой
  грани вытягивает профиль до ДАЛЬНЕГО пересечения с продолжением поверхности (раскос 281,7 мм → 2877,8 мм), side
  не влияет — проверено на выпуклой и вогнутой грани, в обе стороны профиля, при указании грани у самого
  пересечения. Раскос к поясу-дуге — `joint_cut(раскос, пояс)`: подрезает по телу пояса или удлиняет до него
  (адрес пояса — `extra.shaping` ошибки); грань не объекта EasySteel — вырез КОМПАС только по телу профиля.
- Вспомогательную плоскость `cut`/`cut_many` не берут (`bad_surface`): у плоскости нет граней — щелчком её не
  указать, а выделение при открытой команде поле «Поверхности» не принимает.
- `angle_cut` возвращает список — объект на каждый узел цепочки.
- `copy_to`: обработка, привязанная к соседу (стыковая разделка по формообразующему профилю), в копии
  невалидна, а копия профиля — полной длины: ошибка `invalid_copy`, созданное удалено. Копируйте профиль без
  неё и делайте `joint_cut` на копии; `drop_invalid=True` — оставить валидные копии.
- Указание щелчком: цель не видна — движок наводит вид (центр и масштаб проекцией, узкая грань — до 0,03 мм/px),
  закрыта или обращена от камеры — поворачивает вид к ней; после команды вид возвращается как был
  (`view_restored`). Не нашлось видимой точки и так — `not_visible`: укажите объект целиком или видимую точку.

## Ведомость, спецификация, чертежи, ЧПУ

```python
easysteel.parts()          # детали: тело, сортамент, размер, материал, длина, масса по телу (с вырезами)
easysteel.statement()      # {'rows': [{kind, sortament, size, material, count, length_mm, mass_kg}], 'total_mass_kg'}
                           # длина по факту; у профилей после вырезов КОМПАС — length_nominal_mm, by_geometry, note
easysteel.spec_objects()   # строки спецификации тел без строк (в этапе) → {'created', 'skipped'}
easysteel.spec_rows(); easysteel.spec_delete([uid])
easysteel.drawings([п1, п2], folder=r"…\dr", designation=["МК.01.001", "МК.01.002"])   # → {'drawings': [.cdw]}
easysteel.dstv([п1, п2], folder=r"…\nc")    # файлы *.nc командой приложения (модель сохранена на диск)
easysteel.nc1(профиль, r"…\beam.nc", order="З-1", drawing="МК.01")   # свой NC1 с размерами сечения
```

- `spec_objects`: детали — раздел 20 «Детали», крепёж болтового соединения — 25 «Стандартные изделия»
  (`section=` — один раздел для всех); строка на тело, одинаковые не группируются (количество 1).
- Строка спецификации — объект спецификации КОМПАС на теле, наименование — имя тела («Профиль@/Двутавр $b 20Б1
  …;С235 …$@/L = 1000 мм»: @/ — перенос, $b…;…$ — дробь). Команда приложения «Создать объекты спецификации для
  выбранных» из скрипта ничего не создаёт. Строка, созданная в test_exec, после отката остаётся висеть — пробуйте
  в документе, который потом закроете без сохранения.
- `drawings`: модель должна быть сохранена (приложение само её сохраняет — `app_saved`); по вызову команды на
  объект, файл «<обозначение> <наименование>.cdw». Приложение переименовывает тело в наименование чертежа и пишет
  обозначение в тело — длину профиля либа тогда меряет по геометрии. **После вызова КОМПАС держит вопрос
  «Изменена модель… Перестроить чертеж?» — ответить «Нет» (инструмент dialog) до `change_end`**: с висящим
  вопросом `change_end` оставлял КОМПАС без документов (только перезапуск). Вопрос бывает и посреди вызова
  (второй объект, `dstv`) — тогда вызов отвечает `dialog_pending`: «Нет» инструментом dialog, вызов продолжится.
  Чертежи открыты (иногда двумя окнами; `drawing_read` по имени файла при двух окнах может ответить «не открыт» —
  по пути) — закрыть `document_close` после `change_end`.
- `dstv`: приложение пишет в папку модели (поле «Папка» из скрипта не задаётся), либа переносит файлы в folder.
  Заголовок у приложения без размеров сечения и с материалом детали КОМПАС; `nc1` пишет свой заголовок (сталь,
  профиль, код I/U/L/T/RO/RU/M/B, длина, h, b, t, s, r, масса метра) — без резов торцов и отверстий.

## Чего пока нет

- Прокол (34) и Заделка (39): тип «Угловые профили» и вырез «Равнополочный Тип 1» задаются, пластина указывается,
  а уголок ГОСТ 8509 сквозь пластину поле «Профили» не принимает (видимо, нужен судовой уголок/полособульб) — не
  доведено.
- Специальная разделка (24), трёхмерный каркас (999), профили по образующим (7), образующие перемещением СК (5),
  конфигурация (8 — окно настроек приложения), вставка сечения в 2D (18), типовые соединения (30/31), «Получить
  параметрические данные профиля» (35 — по s38 зависает) — не делались.
- Разбить пластину: объект создаётся, число тел не меняется (деление условное) — что делится, не проверено.
- Поясок: обрезка торцов, «Положение пояска», сортамент из каталога; пластина по грани — сортамент «Нестандартный
  лист» (выбор сортамента — окном каталога), «Сменить направление».
- Фаска «Поменять местами» (по двум сторонам — поменяйте L1/L2); паз типа 3 отдельно не проверялся.
- Чертежи: один объект на вызов команды; виды и масштаб — как предлагает приложение.
- `nc1` — без блоков отверстий (BO) и резов (AK).
- Таблицы без формы сечения (составные, спаренные, особые гнутые) — `no_shape` (`find` → `buildable: false`); ребро
  формы 5 (a, b) не строится.
- `cut` по непрямой грани (ошибка приложения) и по вспомогательной плоскости (указание плоскости щелчком движок
  `_appui` не умеет) — отказ; обход — `joint_cut` или вырез КОМПАС по телу профиля.
