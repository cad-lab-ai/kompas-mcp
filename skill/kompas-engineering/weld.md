# weld — «Сварные соединения» из скрипта

Либа-адаптер приложения «Сварные соединения» КОМПАС-3D v19: Libs\WeldConnect (WeldConnect.rtw — обозначение шва
по ГОСТ, 2D-команды, настройка) и скрытое Libs\Welding3D (Welding3D.rtw, «Сварные соединения в модели» — швы в
модели; в Менеджере библиотек его нет, запускается по пути). В неймспейсе `code_exec`, `query`, `test_exec` — имя
`weld` (в установленном плагине без нового host.py — `from kompas_agent.libs import weld`). Создание и правка —
внутри этапа, чтение — где угодно. Ошибки — `weld.WeldError` (`code`, `message`, `extra` — варианты, состояние
команды и окна).

Две части: **шов в модели** — объект самого приложения, создаётся его командой (~25–30 с на шов); **обозначение на
чертеже** — своими средствами API 2D (линия-выноска по ГОСТ 2.312), не командой WeldConnect. Изображения швов на
чертеже (штрихи, крестики, катет) — либа [weldseam](weldseam.md).

КОМПАС v23: приложение называется «Неразъемные соединения» («…в модели» — Welding3D). До первой настройки его любая
команда открывает «Мастер настройки параметров приложения» (Отмена открывает его снова) — `create`/`edit` шва сразу
отказывают `WeldError('setup_required')` (нет файлов `*.cfg` в `%APPDATA%\ASCON\KOMPAS-3D\23\WeldConnect`):
мастер проходит человек в своём КОМПАС один раз (настройка общая для всех КОМПАС v23 пользователя). Обозначения на
чертеже (`mark…`, `table`) приложением не пользуются и работают без настройки.

## Шов в модели

```python
f1 = find(type="face", ...)[0]; f2 = ...                       # грани РАЗНЫХ тел: адрес {obj, sub} из find или IFace
w = weld.create(f1, f2, joint="Т1", leg=6, name="Шов ребра")   # → info нового шва
weld.create(f1, f2, standard="ГОСТ 14771-76", joint="Т1", method="ИНп", leg=4, length=50, step=100)  # прерывистый
weld.create(f1, f2, joint="Т3", leg=5, leg2=4, length=40, step=80, staggered=True)   # двусторонний шахматный
weld.create(f1, f2, joint="Т1", leg=4, roughness="Rz 20", after_shelf="Шов 2", control="УЗК")
weld.items()              # [{ref, name, text, text_raw, standard, joint, method, leg, leg2, intermittent, roughness,
                          #   after_shelf, control, line_length, weld_length, mass_kg, faces, valid, mass_method}]
weld.info(w["ref"])       # шов по ref / 'weld:<ref>' / dict из items / объекту / имени в дереве
weld.faces(w["ref"])      # опорные грани [IFace]
weld.edit(w["ref"], leg=8)   # → info нового шва, replaced — ref прежнего; прочие поля и имя переносятся
weld.edit(w["ref"], joint="Т1", length=None, step=None)   # Т3→Т1 (оборотная сторона отпадает), непрерывный
weld.delete(w["ref"])
weld.parse(blob)          # разбор блока UserParams шва (bytes)
```

- Шов — пользовательский объект обозначения 3D (IUserObject3D, тип 607) библиотеки Welding3D; опорные объекты —
  [базовая плоскость | None, грань 1, грань 2]. Параметры — блок UserParams (строки обозначения WeldConnect со
  спецзнаками КОМПАС: «@+34~» — катет, «@+84~» — катет оборотной стороны, «@+15~» — прерывистый цепной «/»,
  «@+39~» — шахматный «Z», «@+171~» — шероховатость; за ними — текст за полкой и контроль), длины и масса —
  переменные объекта. `text` — читаемый текст обозначения, `text_raw` — со спецзнаками.
- `create(face1, face2, …)` — способ «По граням и ребрам», односторонний. **Объекты — грани или рёбра разных тел**
  (детали сборки, тела многотельной детали; так требует Welding3D), видимые в окне: указание — щелчком по экрану.
  Закрытую грань движок указания открывает сам: приближает по ширине грани, поворачивает вид (по нормали, наискосок
  к ней, с осей — откуда видна большая часть) и щёлкает в незакрытую точку грани; скрывать соседей и указывать
  точкой `[x, y, z]` вручную не нужно. Грань из `find` — адрес `{obj, sub}`, и у стандартных изделий тоже.
  Тавр, угол, нахлёст — две грани, на пересечении которых шов. Грани одного тела — `WeldError('same_body')` сразу.
- Параметры окна обозначения: `standard` (начало пункта: `'ГОСТ 14771-76'`), `joint` (`'С1'`, `'Т1'`, `'У4'`,
  `'Н1'`…), `method` (способ сварки, напр. `'ИНп'`), `leg` — катет, мм; `length` + `step` — прерывистый
  (участок/шаг, только вместе), без `length` — непрерывный; `staggered=True` — шахматный «Z», только у
  двустороннего прерывистого (нужны `leg2` и `length`, иначе `bad_staggered`: щелчок «Z» у одностороннего ронял
  КОМПАС). `leg2` — размер оборотной стороны (двусторонние Т3, С7…), `roughness` — шероховатость (`'Rz 20'`),
  `after_shelf` — текст за полкой, `control` — контроль шва, `name` — имя в дереве (имена по умолчанию одинаковы —
  `info(имя)` тогда `ambiguous`). Не задано — как в окне по умолчанию (незаданные поля окну сбрасываются).
- **В модели не хранятся** (окно принимает, блок шва тот же): `hide_standard=True` и `roughness2` —
  `WeldError('not_supported')` с обходом на чертеже (`mark(hide_standard=True)`, `mark(text=…)`).
- После создания либа сверяет заданное с блоком шва: не попавшее — в `not_applied` `{поле: [задано, в шве]}`.
  Сбой окна без причины («OK» не закрыл окно, шва нет при закрытом окне) — один повтор, `retried: true`.
- `values` — прочие поля панели Welding3D (`{'Показывать обозначение': False}`); `'Наименование'` приложение с
  панели не берёт — либа ставит его как `name`. `dialog` — свои действия окну перед «OK»:
  `[('combo', '#n', пункт) | ('check', подпись, bool) | ('edit', '#n', текст)]`.
  `doc` — документ, путь или имя окна открытого документа; `limit` — предел времени команды, с (60).
- Окно отказало (значение вне ряда) — `WeldError('dialog')` с текстом окна (~14 с); шва нет —
  `WeldError('not_created')`: шаги команды, значения полей окна и подсказка (второй объект не принят — не то
  тело или не виден; «Создать» недоступна — грани не пересекаются).
- `edit` — пересоздание: новый шов на тех же гранях, затем удаление прежнего; ref меняется. Не заданное
  переносится: стандарт, тип, способ, катет, оборотная сторона (если у нового типа она есть: Т3→Т1 — отпадает),
  прерывистость (шахматный на одностороннем становится цепным), шероховатость, текст за полкой, контроль, имя.
  Снять — `None` (`length=None, step=None` — непрерывный, `after_shelf=None`). Неизвестный параметр — `bad_param`.
- **Этап и откат.** Шов — объект приложения: в эффекте вызова он в `effect.app_objects` (создан/изменён/удалён,
  `uobj:<ref>`), правка шва — не `no_effect`. Откат этапа (`change_abort`/`change_undo`) — Undo и удаление швов,
  которых в начале этапа не было (команда шва пишет свою запись отмены: Undo этапа возвращал удалённый прежний
  шов, а новый оставлял). На установленном ядре старше этой правки швов в отпечатке нет: verdict `no_effect`
  ложный, откат `edit` возвращает прежний шов, но новый остаётся — после отката проверяйте `weld.items()`.

## Обозначение на чертеже (ГОСТ 2.312)

```python
m = weld.mark((50, 20), (70, 35), joint="Т1", leg=6)              # стрелка в точку шва, полка от точки shelf
weld.mark([(10, 0), (40, 0)], (60, 20), joint="С2", side="back")  # две ножки (одинаковые швы), под полкой
weld.mark((0, 0), (-30, 15), joint="Т1", leg=4, length=50, step=100, roughness="Rz 20",
          closed=True, mounting=True, after_shelf="Шов 1")
weld.mark((0, 0), (20, 10), text="ГОСТ 5264-80-Т1-@+34~5")       # готовый текст со спецзнаками
weld.marks(view=1)        # [{ref, addr, view, text, text_raw, fields, side, at, shelf, closed, mounting, after_shelf}]
weld.mark_info(m["addr"]) # addr 'view:1/sym:<Id>' переживает переоткрытие и откат; ref — нет
weld.mark_edit(m["ref"], leg=8, side="back", shelf=(80, 40))
weld.mark_delete(m["ref"])
weld.designation(joint="Т1", leg=6, length=50, step=100)          # 'ГОСТ 5264-80-Т1-@+34~6-50@+15~100'
weld.table((200, 150), model=r"C:\...\деталь.m3d")               # таблица швов из швов модели
weld.table((200, 150), rows=[["1", "ГОСТ 5264-80-Т1-@+34~6", "100", "0,02"]])
```

- `mark(at, shelf, …)` — простая линия-выноска КОМПАС (по умолчанию с полустрелкой): `at` — точка шва (x, y) или список точек
  (несколько ножек), `shelf` — начало полки; полка вправо/влево — по положению `shelf` относительно первой точки.
  Координаты — вида (`view` — номер или IView, по умолчанию активный). Текст — из полей окна WeldConnect
  (`standard` по умолчанию `'ГОСТ 5264-80'`, `joint`, `method`, `leg`, `length`/`step`, `roughness`,
  `hide_standard`, `staggered` — шахматный «Z») или `text` целиком. `side='front'` — над полкой (лицевая сторона), `'back'` — под полкой;
  `closed` — шов по замкнутой линии (кружок на изломе), `mounting` — монтажный (флажок), `after_shelf` — текст за
  полкой, `arrow` — `'up'` | `'down'` | `'arrow'` | `'none'`. Внутри этапа.
- Своих данных у выноски нет: `marks` / `mark_info` / `mark_edit` читают сам текст и разбирают его на поля
  (`fields`). Обозначением шва считается простая выноска (стрелка любая) с текстом, который начинается со
  стандарта (ГОСТ, ОСТ, РД, ISO, EN…) или содержит знак катета, — и человеческие выноски такого вида тоже.
  Обозначение — ref, адрес `view:n/sym:<Id>` или запись `marks()`; иное — `bad_ref`, точка не (x, y) — `bad_point`.
- После сохранения и открытия чертежа КОМПАС кладёт текст за спецзнаком в элемент «конец знака»: либа его читает
  (катет не теряется, `mark_edit` его сохраняет).
- `mark_edit` — поля текста (`standard`, `joint`, `method`, `leg`, `length`, `step`, `roughness`,
  `hide_standard`) или `text`, `side`, `closed`, `mounting`, `after_shelf`, `at`, `shelf`, `arrow`; неизвестный
  параметр — `bad_param`; текст не разобран на поля — `free_text` (меняйте `text` целиком).
- `table(at, rows=None, model=None, columns, view, doc, row_height=8, widths)` — таблица чертежа: столбцы по
  умолчанию «№, Обозначение шва, Длина, мм, Масса, кг»; строки — `rows` или швы модели `model` (путь или документ;
  должна быть открыта). `at` — левый верхний угол в координатах вида. → `{ref, rows, view}`.

## Команды панелью приложения (нижний уровень)

`weld.ui` — общий движок `_appui`: `ui.run(cmd, steps, values, …, app=ui.APP3D | ui.APP)`, `ui.commands(app)`,
`ui.start`, `ui.fields`, `ui.press`, `ui.pick`, `ui.cancel`, `ui.state`. `APP3D` — Welding3D (2 — обозначение шва в
модели, 3 — информация о швах), `APP` — WeldConnect. `weld._win` — ответы окнам WeldConnect (`answer_later`,
`controls`, `set_combo`…). Нужны только для того, чего нет наверху.

## Грабли

- **Создание — только командой.** `UserObjects.Add(607)` отдаёт None: копией блока шов не создать. Команда идёт
  целиком в одном `ui.run` (указание граней → окно обозначения → «Создать» вложенной панели WeldConnect → «Создать»
  Welding3D → «Отмена» панели): между вызовами указания теряются.
- **Окна WeldConnect не реагируют на «OK» без фокуса ввода** (сторож фокуса, заблокированный экран). Либа жмёт
  «OK» из фонового потока с AttachThreadInput + SetActiveWindow + SetFocus + BM_CLICK; ответ — таймером
  UI-потока.
- **Рабочие фрагменты ks*.tmp.** Команда шва создаёт невидимый фрагмент в %TEMP% и держит его. Закрывать их
  нельзя: КОМПАС падал на следующей команде шва или закрытии модели. Ядро с `stage.app_work_doc` их не проверяет
  как чужие; на старом ядре следующий вызов, правящий такой фрагмент, давал other_document и откат (вместе со
  швом) — там `create` по-прежнему закрывает их (`weld.model.close_temp()`), с риском падения.
- **Таймер ответа окну** останавливается в конце вызова: таймер вызова, упавшего до окна, отвечал окну следующего
  вызова своими значениями (второй ответ одному окну).
- Флажки окна (кнопки-картинки «/», «Z», знаки) щёлкаются синхронно; их BM_GETCHECK недостоверен — результат
  сверяется по блоку шва (`not_applied`).
- **Окно обозначения помнит прошлые значения** (участок/шаг, шероховатость, тексты): `create` сбрасывает всё, что
  не задано. Поля окна — по id элементов: порядок «#n» зависит от типа шва.
- Швов нет в `find(type='operation')` — читать через `weld.items`.
- Повисшую команду Welding3D Esc не снимает — снимать «Отменой» панели (UIA |STOP_BUTTON).
- Перезагрузка модулей `_appui` в живом КОМПАС рискованна: после правки движка — перезапуск своего КОМПАС.

## Чего пока нет

- **Вспомогательные знаки ГОСТ 2.312 в шве модели** (усиление снять, плавный переход, по незамкнутой линии,
  по замкнутой линии «○»): кнопки-картинки окна сообщением не меняют данные окна — ни поставить, ни снять;
  «○» однажды залип в памяти окна до перезапуска КОМПАС. На чертеже (`mark`) кружок замкнутой линии есть.
- **Стыковые швы в модели** (С…): ни одна проверенная пара указаний не дала линию шва — обозначение стыка только
  на чертеже (`mark`).
- **Шероховатость оборотной стороны и «не показывать стандарт»** в шве модели (приложение не хранит).
- **Способы «По ребрам», «По точкам»**, двусторонние и одинаковые швы в модели.
- **Правка шва без пересоздания** (ref меняется).
- **Сервисные команды WeldConnect**: 201 технические требования, 202 конструктивные элементы, 215/216 номера и
  количество одинаковых, 217 проверка по ГОСТ, 218, 219 применить свойства, 220, 221, 222 редактор
  свойств, 223 3D→2D, 229 настройка (мастер), 194/214 информация о швах — не обёрнуты.
- **Обозначения на чертеже — не объекты WeldConnect**: двойной щелчок панель приложения не открывает,
  разбор обозначений, построенных командой 200 приложения, не проверялся.
