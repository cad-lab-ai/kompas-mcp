# vdm — КОМПАС-VDM (вариационное прямое моделирование)

Приложение `Libs\KompasVDM` КОМПАС-3D v19: геометрические и размерные ограничения на грани/рёбра/вершины детали
**без истории построения** (и импортированной); решатель приложения (LEDAS) сам перестраивает тело. Только деталь.
Либа работает с данными приложения напрямую — через экспортированные C++-классы KompasVDM.rtw, без мыши, панели и
окон. Менять — в этапе (`change_begin → code_exec → change_end`); чтение (`constraints`, `entities`, `info`) — в
`query`.

**КОМПАС v23** приложения КОМПАС-VDM нет (ни в `Libs`, ни в списке приложений) — функции отказывают `VdmError` с кодом `no_app`.

```python
vdm.entities('face')                 # [{ref:'face:3', surface:'plane'|'cylinder'…, area, box, point, normal, radius, height}]
vdm.add('distance', [[0,30,10], [100,30,10]], 120)    # грани по точкам → {created, args, box, box_before, all_satisfied}
vdm.distance('face:1', 'face:3', 50)                    # оси отверстий; 'XY'/'XZ'/'YZ', 'X'/'Y'/'Z', 'O' — объекты СК
vdm.radius([20,30,10], 12); vdm.angle(a, b, 80); vdm.parallel(a, b); vdm.fix(a, b); vdm.rigid(a, b)
vdm.add('distance', [L, H1, H2], 35, mode='chain')    # групповое: 'chain' (1-2, 2-3…) | 'center' (1-2, 1-3…)
vdm.add('distance', [top, 'XY'], 'H')                 # выражение от переменных детали
vdm.constraints(); vdm.info('Расстояние 1')   # [{name, kind, value[, expression], args, satisfied}]
vdm.edit('Расстояние 1', 150, new_name=None); vdm.delete('Радиус 2') / vdm.delete(all=True)
vdm.push_pull([50,5,20], 5)          # сдвиг грани наружу из материала: плоская — по нормали, вал — радиус больше, отверстие — меньше
vdm.rebuild(); vdm.prepare(); vdm.history()
vdm.mass()                           # {mass_kg, volume_mm3, center} по телам — верные после правок VDM
vdm.show_dimensions(True)            # выноски размерных ограничений (макро с 3D-размерами)
vdm.options.read()                   # 3 флажка из памяти (query); read(full=True) — все 5 через окно (только в этапе)
vdm.options.write(autoupdate=False)
```

- `entities`: `point` лежит на самой грани и однозначно указывает её (годится аргументом), `normal` плоской грани —
  наружу из материала, `height` цилиндра — длина вдоль оси.
- Выражение (`'W'`, `'L*2'`) — только от существующих переменных детали: иначе `unknown_variable` до вызова
  приложения (неизвестное имя приложение принимает, пересчёт падает «Ошибкой при перестроении»).
- `edit` числом ограничения, заданного выражением, → `bound_to_expression` (меняйте переменную или передайте
  выражение); `unbind=True` — заменить выражение числом.
- **Масса**: МЦХ детали (`model_overview`, `effect`, ksPart.CalcMassInertiaProperties) КОМПАС после правок VDM не
  пересчитывает — масса и центр масс прежние, объём новый; не лечится ни перестроением, ни сохранением. Верные —
  по телам: поле `mass` в ответах либы и `vdm.mass()`. Переключение режима МЦХ детали «вручную → авто» массу детали
  обновляет, но портит центр масс тела — так не делать.

**Объекты-аргументы**: `'face:N' | 'edge:N' | 'vertex:N'` (номер из `entities`), точка `[x,y,z]` — грань под точкой,
`{'edge': p}` / `{'vertex': p}`, объекты СК, объект API (IFace/IEdge/IVertex — по геометрии). Точка на ребре грани —
ошибка `ambiguous` с вариантами. Номера граней меняются при удалении истории и при пересчёте с другой топологией —
точки надёжнее. У рёбер/вершин в конце списка есть оси/начало СК (кривая `curve`, точка 0,0,0) — для них `'X'`, `'O'`.

**Как пересчитывается**: при «Автоматическом обновлении» (по умолчанию) — сразу в `add`/`edit`. Решения нет —
ограничение снимается / значение возвращается, ошибка `no_solution` с `messages` (`keep=True` — оставить). Сообщения
приложения («Решение задачи не найдено», «После перестроения остались неудовлетворённые ограничения») отвечаются
сами и приходят в `messages`. Решатель волен двигать что угодно не закреплённое: одно расстояние может сдвинуть тело
целиком — закрепляйте опорные грани (`fix`) или используйте `push_pull` (он на время фиксирует несмежные грани).

**Модель с историей**: `add`/`push_pull` сами вызывают `prepare` — `IKompasDocument3D.DeleteHistory` (дерево →
«Операция без истории», форма та же); аргументы, заданные до этого номерами, переносятся по геометрии.

## Покрытие

| Возможность приложения | Функция | Проверено вживую |
|---|---|---|
| Добавить расстояние (грани, оси цилиндров, рёбра, вершины, плоскости СК) | `add('distance')`, `distance` | да |
| Групповое расстояние/угол «Цепь»/«Центр» | `add(..., mode='chain'/'center')` — набор обычных ограничений | да (chain) |
| Добавить угол | `angle` | да |
| Добавить радиус (тор — major/minor) | `radius`, `add('major_radius'/'minor_radius')` | да (цилиндр); тор — нет |
| Совпадение | `coincident` | нет (вызов тот же, что у проверенных) |
| Параллельность / перпендикулярность | `parallel`, `perpendicular` | да |
| Касание | `tangent` | нет |
| Концентричность | `concentric` | да (no_solution и откат) |
| Фиксация (грани, рёбра) | `fix` | да |
| Жёсткое множество | `rigid` | да |
| Выражения от переменных | `value='H*2'` | да |
| Редактирование ограничения (значение, имя) | `edit` | да |
| Удаление ограничения (из списка) | `delete` | да |
| Список ограничений | `constraints`, `info` | да |
| Пересчитать модель | `rebuild` (`command=True` — командой) | да |
| Настройки (5 флажков) | `options.read/write` | да |
| Отображать размерные ограничения | `show_dimensions` | да |
| Сдвиг грани (Push-Pull, в меню нет) | `push_pull` — своими ограничениями через решатель | да, без фиксации остального; с `fix_rest` — нет |
| Редактирование по выноске (двойной щелчок) | `edit` | — |

## Грабли

- **Отмена**: команды приложения «Пересчитать модель», «Отображать размерные ограничения» и окно «Настройки» пишут
  **свою** запись отмены — `change_abort` этапа снимает только последнюю, откат неполный; после таких смешанных
  этапов откат несколько раз ронял КОМПАС (порча кучи, ntdll 0xc0000374: `edit` + `rebuild(command=True)` →
  неполный `change_abort` без переоткрытия → `document_close`). Поэтому `prepare` — через DeleteHistory,
  `rebuild` — пересчётом в данных; `rebuild(command=True)` без `own_undo=True` отказывает. `show_dimensions` и
  `options.write` — отдельным этапом, без отката. Если откат всё же неполный (`complete: false`, нет `reopened`) —
  не закрывайте документ: сохраните копию (`document_save_as`) или сообщите человеку.
- Падение 0xc0000409 (ucrtbase_clr0400) было на `add` с выражением после длинного этапа, где перед этим выражение от
  несуществующей переменной дало «Ошибку при перестроении», а затем `AddVariable` + `RebuildModel` в том же
  вызове. Повторить не удалось; неизвестные переменные теперь отсекаются до приложения. Переменные создавайте до
  ограничений с выражениями, отдельным вызовом.
- Этап, который поменял только ограничения (без геометрии), плагин может не откатить (`change_abort` без undo) —
  проверьте `vdm.constraints()` и удалите лишнее `delete`.
- `effect` плагина в `code_exec` часто не видит замену тела приложением (объём/габарит прежние) — смотрите `box` /
  `box_before` в ответе либы (IBody7.GetGabarit).
- Имена по умолчанию — счётчик приложения общий для всех типов («Радиус 6»), после загрузки начинается заново —
  либа пропускает занятые.

## Чего пока нет

- Тор (major/minor radius), касание и совпадение вживую не проверены.
- `push_pull` с `fix_rest=True` (фиксация несмежных граней) не проверен — КОМПАС упал на откате этапа до проверки.
- Вкладка «Список ограничений» дерева (UI) не открывается либой; выделение ограничения и подсветка аргументов — нет.
- `options.write` двух флажков (интеллектуальные автоограничения, равные радиусы) — только окном (своя запись отмены).
- Причина падений КОМПАС на откате этапов до конца не найдена (см. «Грабли»).
- МЦХ детали после правок VDM (масса, центр) — только по телам (`vdm.mass()`).
